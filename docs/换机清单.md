# 换机 / 换环境清单

探微本身是个 Electron 壳，真正干活的是包里那份 `grok.exe`。所以「换个环境还在不在」要分成两半看：安装包带得走的，和留在本机用户目录里的。

## 安装包自带（换机不用管）

| 东西 | 位置 | 说明 |
|---|---|---|
| 界面、主题、模型配置页、技能页 | `app.asar` | 无外部依赖 |
| grok 引擎 | `resources\grok\grok.exe` | 版本随包走 |
| 工具名修片代理 | `resources\tools\stream-fix-proxy.mjs` | 启动时自动起：`8788` 必起，`8787` 没人监听时补位，退出一起收 |

## 留在本机、必须自己带过去

全部在 `%USERPROFILE%\.grok\` 下：

| 路径 | 不带会怎样 |
|---|---|
| `config.toml` | 模型地址 / 密钥 / `[endpoints] models_base_url` / `[mcp_servers.*]` / `[skills] disabled` / `[ui]` 全没了，探微只能直连 x.ai 默认端点 |
| `skills\` | 技能本体（含 `clown-src-6k-skill`）不在，斜杠菜单里就点不出来 |
| `bin\playwright-dual-slot.mjs` | `config.toml` 里写死了这个绝对路径；缺了浏览器工具直接起不来 |
| `bin\streamfix-proxy.py`、`streamfix-loop.cmd` | 只有 `config.toml` 指向 `127.0.0.1:8787/8788` 时才用得上；默认直连上游，缺了也不影响 |
| `sessions\` | 只影响历史会话列表，想带旧对话才拷 |

另外 `%APPDATA%\tanwei-console\settings.json` 是网络代理那几张档位，换机重设一次即可。

## 目标机要有

- **Node.js**：playwright MCP 走 `node` + `npx @playwright/mcp`（第一次要联网拉包）。
- **Chrome 或 Edge**：`playwright-dual-slot.mjs` 按 `CHROME_PATH` → Program Files Chrome → Edge 的顺序找。浏览器被关掉后，槽位脚本的看门狗每 5 秒查一次，掉了自动重拉。
- **Python 3 + uv**：只有 fofa MCP 需要（`config.toml` 里写的是 uv 的绝对路径，换机要改成目标机的路径）。

## 最小换机动作

1. 装 `TanweiConsole-0.1.0-setup.exe`（或拷 portable 直接跑）。
2. 把旧机 `%USERPROFILE%\.grok\` 里的 `config.toml`、`skills\`、`bin\` 拷到新机同一位置。
3. 装 Node 和 Chrome。
4. 开探微 → 设置页点一次「测试连通性」确认模型通 → 发任务。

## 模型选择（换中转时先看这条）

同一家中转的不同模型，流式分片质量不一样：DeepSeek 系列会把 `function.name` / `id` / `type` 重发成空串，grok 合并后工具名变空，报 `Tool not found:`。

- 要 DeepSeek：走官方 `https://api.deepseek.com/v1` + `env_key = "DEEPSEEK_API_KEY"`，`deepseek-chat` / `deepseek-reasoner` 实测干净，工具正常。
- autorouter 上的四款 DeepSeek 都不干净；同一家的 `kimi-k3`、`glm-5.3` 干净。
- 换模型后用 `grok -p "用 run_terminal_command 执行 echo ok" --model <名> --always-approve` 自测一次。

`[endpoints] models_base_url` 只管拉模型清单，且固定用 `XAI_API_KEY` 做 Bearer；指向 DeepSeek 会 401 并刷 `model catalog refresh failed`（不影响聊天）。

## 便携版的数据目录

便携版 exe 每次运行会解包到 `%TEMP%`，所以配置不能放解包目录。程序按这个顺序找数据目录：

1. exe 同目录下已有 `TanweiConsole-data\config.toml` → 用它；
2. 本机已有 `%USERPROFILE%\.grok\config.toml`（装过 grok）→ 用 `~\.grok`；
3. 都没有 → 在 exe 同目录创建 `TanweiConsole-data\`，并写一份**不含密钥**的初始配置。

所以干净机器上第一次打开 portable，会在 exe 旁边生成 `TanweiConsole-data\config.toml`；把旧机器的配置覆盖进去（或在「模型」页填 key）就能用。整个文件夹拷走，配置跟着走。

「连通性」探测走「设置 → 网络代理」里选的那档（跟随系统 / 手动 / 直连），机器需要 Clash 时选「跟随系统」或填端口即可。

## 已知环境限制

- 浏览器槽位是 `9222` ～ `9225` 四个，第五个同时开的会话会拿不到槽位（脚本会直接退出并打印是谁占着）。
- `web_search` 走 xAI 的 Responses API 和 grok 模型：自建中转的分组里没有该模型时会报 `model_not_found`，改用 playwright 或 curl 抓页面。
- fofa MCP 要有效 FOFA Key；Key 失效时报 `[-101] Key 不存在`，在 MCP 页直接改环境变量即可。
- 探微启动会恢复上一次的会话；如果那会儿同一个会话正在别的窗口跑，先点「新建会话」再干活。
