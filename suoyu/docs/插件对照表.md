## 六、listener（3 / 3 已对齐）

> 口径：xing 目录下 listener 只有 2 个插件文件（`dns.py`、`http_api.py`）；`http_api.py` 内含查询回显记录的 HTTP 接口，索舆要可视化查看还得有前端页，所以算 3 项能力。

| xing 插件 | 能力 | 索舆 |
|-----------|------|------|
| `dns.py` | 带外 DNS 回显 | ✅ `arlx/engine/listener.py`（UDP/TCP 53，dnspython 解析） |
| `http_api.py` | 带外 HTTP 回调 | ✅ 同一模块（HTTP 回调口，记录方法/路径/头/体） |
| `http_api.py` 查询接口 + 前端页 | 查看回显记录 | ✅ `/api/listener/records` + 「带外回显」页 |

xing 的实现依赖 `dnslib` + Flask + Redis，索舆用已装的 `dnspython` + 标准库与既有 FastAPI，零新依赖。
xing 的 `/weblogic/<payload>` `/eureka/<payload>` 会在回调服务里拼 RCE XML 木马，索舆只保留「记录回连」的检测能力，不内置 exploit 模板。

调用方式：`listener.alloc(task_id)` 拿一个一次性回调 token，DNS 域名 `{token}.{listener.domain}`、HTTP `http://{exit_ip}:{port}/{token}`；第三方回连后自动落库到 `listener_hits` 表，按 token 反查任务。
